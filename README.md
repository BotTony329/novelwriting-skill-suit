# novelwriting-skill-suit

**一套七个互相衔接的 AI 写作 Skill，把长篇小说（网文）创作的完整工作流固化下来：立项 → 分章写作 → 强制审校 → 跨会话交接，外加节奏密度与文风蒸馏两个叠加层。**

适用于任何支持 SKILL.md 技能的 AI 助手（Kimi / Claude Code / 其他兼容工具）。

## 解决的痛点

AI 写长篇小说的四个经典翻车现场：

- **设定漂移**——前文伏笔忘记回收、人物前后矛盾、战力崩坏
- **行文空洞**——大段没有信息量的废话
- **章节同质化**——每章都是同一个模子
- **跨会话失忆**——换个对话就忘了写到哪、角色知道什么

这套件把每个环节都变成了 AI 必须执行的强制流程，而不是"建议"。

## 七个 Skill

| Skill | 职责 | 触发示例 |
|---|---|---|
| [`novel-outline`](novel-outline/) | **立项**：先访谈（题材/男女频/爽点/平台），再产出核心卖点、人物卡、世界观、分级大纲、预设结尾与名场面 | "我想开一本新书" |
| [`novel-writing`](novel-writing/) | **分章流程**：动笔前大纲校对、章节反重复纪律、写完强制审校再归档 | "写第16章" |
| [`novel-proofreading`](novel-proofreading/) | **三遍审校**：对照大纲查吃书 → 章内因果与动机 → 模拟挑刺读者，问题三列表交付 | "读者说逻辑不通"（也嵌入每章写作流程自动执行） |
| [`novel-handoff`](novel-handoff/) | **跨会话状态文件**：写前必读、写后必更；附风格DNA提取、连续性六类故障审计、跨AI工具移植协议 | "继续写上一本" |
| [`novel-pacing`](novel-pacing/) | **节奏密度（叠加层）**：每句话必须缴税；蒸馏自爆款《我在精神病院学斩神》的名场面公式与空话删除清单 | "这章太水了，砍一遍" |
| [`style-distillation`](style-distillation/) | **文风蒸馏（叠加层）**：上传喜爱作者的文本 → 调研+分析 → 产出文风规格书 → 按该文风创作 | "用这位作家的笔风写" |
| [`novel-engagement`](novel-engagement/) | **期待感与代入感（签约层）**：开篇即时吸引力三要素、期待感五大发动机、代入感四纪律、憋屈→爽感→感动公式 | "被拒稿了/不勾人/没代入" |

## 工作流全景

```
style-distillation（文风规格书）   novel-pacing（节奏密度）
            ↓ 叠加层：句子质感        ↓ 叠加层：每段密度
novel-outline → novel-writing → novel-proofreading → novel-handoff
   立项访谈        分章写作          三遍审校            跨会话存档
```

## 安装

```bash
# 1. 下载（整包）
#    Release 附件或仓库根目录的 novel-suite.zip

# 2. 解压后把七个文件夹复制到你的 skills 目录：
#    Kimi / Kimi Code:   ~/.agents/skills/
#    Claude Code:        ~/.claude/skills/
#    项目级:             <项目>/.agents/skills/

# 3. 重启 AI 工具或开新会话即可，无需配置
```

验证：对 AI 说"我想开一本新书"。它开始向你访谈题材而不是直接开写，即安装成功。

## 快速上手

```
我想开一本新书，发在番茄，女频，主题：患癌女友的最后100天。帮我走立项流程。
```

```
按大纲写第1章，2000字。
```

```
（新会话）继续写我的小说，下一章。
```

```
用 novel-pacing 的密度清单把这一章砍一遍，高潮按名场面公式重写。
```

```
这是我最喜欢的作者的书（上传文件），蒸馏他的文风，之后都按这个文风写。
```
