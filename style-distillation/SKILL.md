# 文风蒸馏（Style Distillation）

把"我喜欢这个作者"变成一份 AI 可执行的文风规格书。

## 流程（四步，不可跳步）

### 第一步：取样

- 引导用户上传该作者的文本：txt/docx/pdf/md 均可，粘贴片段亦可。**样本量下限：3000 字、3 个不同场景类型**（对话场景/动作或冲突场景/抒情或日常场景）——只读一种场景蒸出的是场景习惯，不是作者风格。
- 文件在 Downloads/微信缓存等外部位置时先复制进工作区再处理；扫描版 PDF 无文字层时，渲染代表页为图片后视觉阅读（参考 hori-tatsuo-style 的创建过程）。
- 大型文本（整本书）：不逐章读，采样"开头 + 公认名场面 + 结尾高潮"三处（用章节标记 grep 定位），另随机抽 2-3 个中段章节。

### 第二步：调研

用网络检索补齐文本外的维度：作家的流派归属、师承与受影响者、评论界对其文笔的公论、译者风格（若读的是译本，须注明蒸馏的是"原作者×译者"的合体风格）。调研结论只作背景，**笔法规则必须从样本原文中蒸出来，不许拿评论当规则**。

### 第三步：蒸馏（产出风格规格书）

逐样本做笔法批注，再抽象成规则。规格书必须包含六块：

1. **风格核心**：一段话说清此人的美学主张与气质（附一条真实评论佐证）
2. **笔法规则（5-9 条）**：每条 = 规则名 + 一句话说明 + 样本原文例句。**只写行为，不写形容词**——"纯洁透明的文笔"不可执行；"先落感官细节再让心绪渗出"才可执行
3. **句子级笔法**（骨架之上的血肉，缺了这块蒸出来的只有"骨架马马虎虎、句子完全不像"）：逐类从样本里抄实例、找规律——
   - **对白力学**：一句台词承担几层功能？话里怎么藏刀/藏糖（如恶毒婆婆型角色一句"关心"里嵌几个刺）？抄 5 句样本台词，逐句拆"表层意思/实际攻击点/听话人反应"
   - **微表情与微动作**：写情绪时作者给的是什么具体表情+动作节拍（"丈夫啥表情"这类）：不命名情绪（"他很难过"），只给可拍摄的画面。按情绪类别（怒/悲/心虚/宠溺/得意…）各抄 2-3 个样本写法
   - **句长节奏**：长短句怎么搭配，紧张处句长、抒情处句长各是什么分布；标点和语气词习惯
   - **对话与叙述的比例与织法**：对话中间插不插动作/心理，插多少，怎么断句
4. **主题库存**：该作者反复书写的主题与场景类型
5. **禁忌清单**：写这种文风时**禁止**出现的东西（从"什么会破坏它"反推）
6. **批注样本**：保留 5-8 段原文 + 逐段批注（这段用了哪几条规则），供创作前校准笔感

规格书落盘为工作区文件（如 `<作者>-style.md`），给用户审核。**用户确认后文风才算蒸馏完成**——审核点：规则是否"就是这个人"、有没有该作者绝不会说的话混入。

### 第四步：按文风创作

创作前先重读规格书的批注样本校准；写完按规格书自检：逐条规则核对 + 检查有没有违反禁忌 + 对比样本语气。交付时附简短笔法说明（用了哪几条规则），供用户验收。

## 防翻车条款

- 蒸馏的是**风格**，不是内容：禁止复用该作者的具体人物、情节、招牌句子；标志性意象只可在致敬任务中经用户同意后引用
- 样本不足三千字时明确告知"只能蒸馏出初步印象"，规格书标注置信度，后续样本到位后迭代
- 译者风格不可忽视：中译本样本蒸出的规则默认归于译本合体，用户要求"原味"时须提示找原文样本
- 规格书是活文档：用户审核批注的意见回写进规格书

本 skill 产出的是"文风规格书"（如已有的 hori-tatsuo-style 即本流程的一次实例）。创作时与 novel-outline / novel-writing / novel-pacing 叠加：那些 skill 管结构流程节奏，规格书管句子质感。
