# 文风规格书模板

蒸馏完成后按此结构落盘（`<作者>-style.md`）。填写示例见已完成的 `hori-tatsuo-style`（references/excerpts.md）。

```markdown
# <作者名>文风规格书
（样本来源：<书目/篇目>，<译者>译本 | 样本量：约 X 字 | 置信度：高/中/初步印象）
（调研背景：<流派、师承、评论界公论，一两行>）

## 风格核心
（一段话：美学主张 + 气质 + 一条真实评论佐证）

## 笔法规则
1. **规则名**：可执行的行为描述。例："<样本原文例句>"
2. ...

## 句子级笔法
### 对白力学
（抄 5 句样本台词，逐句拆：表层意思 / 实际攻击点或情感功能 / 听话人反应。总结规律：一句话藏几层、怎么藏刀藏糖）
### 微表情与微动作库
（按情绪分类：怒 / 悲 / 心虚 / 宠溺 / 得意…，每类抄 2-3 个样本的具体表情+动作写法。禁止"他很难过"式命名情绪，只收可拍摄的画面）
### 句长节奏
（紧张处与抒情处的句长分布；标点、语气词、口癖习惯）
### 对话与叙述的织法
（对话中动作/心理插笔的位置与频率）

## 主题库存
（反复书写的主题与场景类型）

## 禁忌
- （写这种文风时禁止出现的东西）

## 批注样本
### 样本 1：<场景名>
> <原文段落>
【批注】用了规则 X、Y：<具体指出哪句对应哪条>

（共 5-8 段，覆盖对话/冲突/抒情三类场景）

## 常用词汇与语气标记
（该作者的标志性副词、句式尾缀、标点习惯）
```

## 批注的写法要求

- 批注必须指到具体句子（"落叶的味道里夹杂着菌类潮乎乎的气息" → 规则1：感官先行），不写空泛赞美
- 每条规则至少有一段样本佐证；没有样本佐证的规则是评论，不是笔法
- 场景类型须多样：三段对话场景批不出动作场景的规则
