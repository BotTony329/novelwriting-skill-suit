# 章节审校（防"看客说逻辑不通"）

## 总原则

写完一章 ≠ 完成。**没过多遍审校的章节不许交付。** 审查时切换身份：你不再是作者，是拿了放大镜的挑刺读者。作者知道你想写什么，所以会自动脑补漏洞——审查时必须只信纸面上的字。

顺序**从大到低**：先逻辑与结构，后句子与错字。先改错字再重写段落是浪费。

## 审前准备

读三样东西再开审：`outline.md`（大纲+伏笔表+写作红线）、`handoff.md`（人物状态快照、前文摘要）、本章正文。无这些文件时，让用户提供大纲或至少前几章摘要。

## 第一遍：对照大纲（外部一致性）

- [ ] **情节 beat 对得上**：本章承诺的 beat 完成了吗？有没有写偏到别的情节线上？
- [ ] **设定无冲突**：人物等级/能力/身份/伤势与前文一致？查"吃书"信号：死人复活、能力倒退、名字写错、地点瞬移。
- [ ] **时间线咬合**：本章内时间流逝、与上章的时间衔接（"三天后"真的过了三天吗）、季节节日是否对得上。
- [ ] **伏笔状态**：本章埋的伏笔登记了吗？到期的伏笔收了吗？本章有没有**无意中**与旧伏笔矛盾？
- [ ] **人物状态**：本章结束时每个人在哪、伤势如何、知道什么信息——与 handoff 快照衔接得上吗？**特别查：角色知道了他不该知道的事**（信息泄漏：角色A没经历过某事件却据此行动）。

## 第二遍：章内逻辑（内部自洽）

- [ ] **因果链闭合**：每个结果都有因，每个因都有果。逐事件问"为什么会发生这个？"——答案是"剧情需要"的地方就是逻辑洞。
- [ ] **动机检查**：每个角色的每个关键行动，问"以他此刻的性格和掌握的信息，他会这么做吗？"反派不许为了输而降智，配角不许为主角让路而做不符合自身利益的事。
- [ ] **巧合限额**：一章最多一个巧合，且巧合只能让主角**陷入**麻烦，不能**解决**麻烦。
- [ ] **视角泄漏**：第一人称/限知视角下，有没有写出"我"不可能看到的场景与心理？
- [ ] **信息链**：反转和揭秘依赖的线索，前面真的埋了吗？读者理论上能否自己推出来？（埋了但太隐晦=没埋）
- [ ] **规则一致性**：本章新用的能力/规则，与世界观既有规则兼容吗？临时新增规则有没有付代价？

## 第三遍：看客模拟（读者视角）

像完全没参与写作、只看正文的读者一样重读，找这些点：

- [ ] **跳跃感**：哪里需要读者自己脑补才能接上？（场景切换无交代、情绪突变无铺垫）
- [ ] **含糊指代**："他/她/这/那"会不会指错人？
- [ ] **该写的没写**：承诺过的场景（上一章钩子）兑现了吗？章末钩子是否真的勾人？
- [ ] **出戏点**：现代梗/网络用语出现在古代背景、角色说出不符合身份的话。
- [ ] **情绪真伪**：感动/愤怒/悲伤是挣来的还是作者宣布的？（"他很愤怒"是宣布；摔东西是挣来的）

## 第四遍：去 AI 文风（读者和编辑最常抱怨的"AI 味"）

逐段扫描下列特征，命中即改写（若项目叠加了文风规格书如 hori-tatsuo-style，与规格书冲突时以规格书为准）：

**句式层**
- [ ] **"不是……而是……"句式**：全章出现超过 1 次即删改，改成直接陈述或具体动作
- [ ] **清嗓词**："值得注意的是 / 某种意义上 / 可以说 / 综上所述 / 首先…其次…最后…"——叙述中出现一律删除
- [ ] **排比段**：连续三段以上同结构排比（"他想起……他想起……他想起……"）拆散改写
- [ ] **句长均衡**：通篇句长差不多、没有短句——紧张处必须有 5 字以内短句砸节奏
- [ ] **"当……时"句式**泛滥：全章超过 2 次即改

**词汇层**
- [ ] **情绪只会"温暖/力量/希望/复杂"**：把抽象情绪词换成具体表情、动作、生理反应（可拍摄的画面）
- [ ] **模板场景词**："月光洒下 / 眉头微蹙 / 嘴角勾起 / 眼中闪过一丝 / 深吸一口气"——出现即替换为本场景独有的具体细节
- [ ] **安全中性词堆砌**：连续抽象形容词（"巨大的、前所未有的、难以言喻的"）删到只剩一个，并落实为具体物件

**比喻与意象层**
- [ ] **宏大空洞比喻**：从日常小事突然跳到宇宙/星辰/命运洪流的比喻，除非前文有铺垫，否则改成人物生活半径内的个人化比喻

**对话层**
- [ ] **对话无对象感**：遮住人名只读台词，能否分出谁在说话？分不出就给角色补口癖、句长偏好、忌讳词
- [ ] **标点**：叙述与对话误用英文引号""的改回中文引号""；破折号、省略号密度过高（一段超过 2 处）即删减

**修复原则**：不靠换同义词糊弄——把抽象落成具体细节，把通用换成只有这本书这个角色才会这么说，允许适度口语瑕疵（真人口吻本来就有毛边）。

## 输出格式（三列表）

审查结果必须以下表交付，**不许只说"检查过了没问题"**：

| # | 问题 | 证据位置（第几段/引原文半句） | 处理决定（已修复/待用户定夺/确认无误判） |
|---|---|---|---|

修复规则：
- 能定位的小修（矛盾、指代、时间线）**当场修复**并在表中标注修复后的写法
- 牵涉大纲走向的大改**列出不改**，问用户
- 修完后更新 handoff（改动记录），若设定有变，回同步 outline.md
- 四遍全过、表中无未决项，才允许说"本章审校完成"

## 禁忌

- 禁止边写边审（写作脑与审稿脑不可同时在线；本章正文完成后才开始审）
- 禁止只查错字不查逻辑——错字是最后一遍的事
- 禁止为了通过审查而降低戏剧冲突——修复逻辑洞要靠补铺垫，不是靠删高潮
