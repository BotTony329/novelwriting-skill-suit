# 《我在精神病院学斩神》笔法拆解与逐段自检清单

蒸馏自《我在精神病院学斩神》（三九音域，番茄 380 万+ 在读，9.7 分）三个样本：第1-3章（黄金开局）、第241章《神明禁行》（中段名场面）、第2020-2021章《这一刀》（大结局高潮）。

## 样本一：黄金开局（第1-3章）的结构

**第1章《黑缎缠目》**——全书第一句不是主角自我介绍，而是路人视角的闲聊："你说……盲人怎么过马路？"——用两个闲人的对话把一个**无法解释的画面**（黑缎缠目、导盲杖扛花生油）推到读者眼前。

结构拆解：
1. 反常画面先行（制造问号）
2. 路人议论承担世界观渗透（"十年前出的意外""精神问题""比撞邪更离谱"——信息全从八卦里挤出来）
3. 一个小善行（牵小女孩过马路）建立人物温度，且暗藏反常："他走得很稳""不像女孩牵盲人，倒像哥哥带小朋友"——**用反常暗示实力，一个字不提他强**
4. 章末抛名字悬念：路人记不清的名字"林……林七夜？"，人名与"十年前七岁失明"的巧合成为下一个谜

**第2章**——谜底给一半：他对医生说"我看到了一个月亮上的天使"。答案比谜更离谱，且**主角自己给出两种互相矛盾的解释**（对医生说真话，又熟练地说"都是妄想"）——读者被锁死：到底哪个是真的？

**第3章**——温情收束：姨妈、表弟、癞皮狗，一顿饭。"简单，艰难，却又莫名的让人安心。十年如此。"——**悬念章之后必接日常锚点**，让读者爱上这个要失去/要守护的家。

教训：全书最核心的设定（精神病院、神明、守夜人）三章里一个名词都没出现，全部靠画面与暗示。

## 样本二：《神明禁行》（第241章）——名场面的九个零件

1. 三段环境写威胁：乌云、黑色巨兽般的海、被摧毁的街道——**威胁可视化，大到灭城**
2. 借军方之口定调："这至少得无量了吧？""克莱因也做不到"——用配角的恐惧标定敌人量级
3. 第一道海浪被无形剑气斩断——先展示结果，人还没出场
4. 主角登场反着写：抱长匣、低头、看脚尖、一步步走——**越强的角色，动作越小**
5. 金句第一遍：低声，"用只有自己能听见的声音"——说给自己听，不是喊给敌人
6. 超自然回应：大海定格、分开——**环境替人物表达力量**
7. 反派给足格：波塞冬识货、给名字、问名字——敌人越强，胜利越值
8. 金句第二遍："我再说最后一次……大夏境内，神明禁行！"——原句重复即爆发
9. 整章没有一句招式名、没有一段打斗过程描写

## 样本三：《这一刀》（第2020章）——大结局高潮的收束结构

1. **全员回归**：最终战每个出场者都是旧识，开战前一句"我们联手布的局，从来就没有输过"+ 三个旧案名的快速闪回——用共同记忆代替铺垫
2. **武器即主题**：斩杀邪神的刀由"十数亿人类的因果"铸成——两千章守护的人间，字面意义上成为武器
3. **第一卷伏笔回收**：最后一根因果丝线，来自第一卷牺牲者赵空城的儿子——用闪回短句（【】内三句旧台词）让读者自己拼出真相，叙述者不解释
4. **传承句式**："这次……轮到我来守护你的全世界了"——对牺牲战友的承诺在此刻兑现
5. **收在预告式金句**："这一刀，你要看好了。""……为什么？""这一刀……会很帅！"——最强的必杀不写威力，写一句轻松的预告，然后一刀收尾："一道贯穿宇宙的刀芒，照亮天穹！"

## 空话检测清单（写完逐段过检）

对每一段问四个问题，全答"否"则删除或改写：

- [ ] 这段给出了读者不知道的新信息吗？
- [ ] 这段让人物更立体了吗（动作/选择/反差）？
- [ ] 这段埋了伏笔或收了伏笔吗？
- [ ] 这段提供了不可替代的情绪价值吗（笑点/泪点/燃点）？

额外的删除信号：
- 出现"不知道怎么回事""一种说不出的感觉""仿佛明白了什么"——偷懒概括，落实为具体感官
- 连续两段无对话、无动作、无信息增量
- 复述上一段已经发生的事件
- 环境描写超过三句且不承担威胁/反衬/藏线索功能
- 心理活动复述外在动作已表达的内容

## 高潮自检清单

- [ ] 威胁是否在高潮前被可视化、定量（借配角之口标定量级）？
- [ ] 高潮人物的动作是否足够小、足够慢？
- [ ] 是否有一句金句说了两遍（先低后高）？
- [ ] 是否省略了过程、直给结果？
- [ ] 是否收在一个画面或一句短话上，而非胜利的总结陈词？
- [ ] 大高潮是否回收了至少一条旧伏笔？
