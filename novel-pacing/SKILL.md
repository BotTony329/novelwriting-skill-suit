# 剧情紧凑与高潮写作纪律（斩神蒸馏版）

## 一句话原则

**每一句话都必须缴税**：要么推进剧情，要么塑造人物，要么埋/收伏笔，要么提供情绪。缴不起税的句子，删。

## 五条铁律

### 1. 悬念先行，背景后置
- 开头不解释世界观，先给一个**无法解释的画面**（范本：黑缎缠目的少年拿导盲杖扛花生油过马路——读者满脑子问号才会追下去）。
- 设定通过**旁观者的议论**和**角色的困境**挤出来，禁止叙述者讲课。
- 核心谜团分层释放：第一章抛谜（他为什么缠眼？），第二章给一半答案（他看见了天使），但答案本身引发更大的谜（天使是真的吗？）。**每个答案必须长出一个新问题。**

### 2. 场景内零废笔
写完逐段过检，删除以下内容（空话的典型形态）：
- 复述读者已知信息的过渡段
- 没有新信息的心理活动（"他心想：这事真奇怪"）
- 纯氛围的环境描写——环境必须承担功能：烘托威胁、反衬心境、或藏线索
- "不知道怎么回事""一种说不出的感觉"这类偷懒概括——必须落到具体感官细节
- 连续两段没有对话/动作/信息增量的段落，合并或删除其一

### 3. 高潮写法：克制即爆发（名场面公式）
范本为"大夏境内，神明禁行"与"这一刀会很帅"，提取出的公式：

1. **先写大，再写小**：灾难/威胁先用三段写到毁天灭地（灭城海浪），然后镜头切到一个人**低着头走向海边**——力量对比越悬殊越好。
2. **以静制动**：高潮人物的动作要极小、极慢（拍一拍剑匣、点一根烟、一句话只说一遍）。威势让环境去喊，人越静越强。
3. **台词只一句，说两遍**：名场面金句先低声说一次（"前方大夏领土，神明禁行"），被挑衅后**原句重复**一次作为爆发点（"我再说最后一次……"）。重复本身就是台词。
4. **省略过程，直给结果**：最强的一击不写招式细节，写"海浪从腰部断开""大海被分开了"——结果即震撼，过程留给想象。
5. **收在画面上**：高潮段落不停在胜利，停在一个人人能记住的画面或一句短到能截图的话上。

### 4. 伏笔的超长线回收
- 第一卷的随口一提（某张照片、某个名字、一句玩笑），要在几百章后成为泪点或爆点。大纲阶段就把"回收点"钉死（衔接 novel-outline 的伏笔表）。
- 大高潮 = **多线伏笔同时收束**的聚会：最终战里每个登场的角色、每件信物都要是读者见过的旧物（范本：结局的刀由全人类的因果铸成，最后一根因果来自第一卷牺牲者的儿子）。
- 回收时要给**恍然大悟句式**：用简短闪回（一句话一条）让读者自己拼出真相，不解释。

### 5. 节奏：张弛交替但以章为单位
- 每章必须有**一个信息增量或一次局面变化**；平章（纯日常/纯过渡）最多一章，且章末必须埋刺。
- 章末钩子四选一：新威胁露头 / 旧谜加深 / 局面反转 / 短句宣言（金句钩子）。
- 大战之后必接"人间烟火"小场景（一顿饭、一句家常）——读者需要喘息，且日常是下一次爆发的燃料。

## 与其他 skill 的分工

novel-outline 管"写什么"（结构），novel-writing 管"怎么不断更"（流程），本 skill 管"写得密不密"（每段每章的密度）。文风 skill 管句子质感。叠加时本 skill 的密度检查在最后执行——先成稿，再砍。
