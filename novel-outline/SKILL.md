# 网文新书立项与大纲创作

## 铁律：三段闸门——访谈 → 计划 → 确认后产出

**未走完三段闸门，不许生成任何正式大纲内容。**

1. **访谈**：用户没给全信息时，一次最多问 4 个问题，从最关键的问起（见下方必问清单）。
2. **出计划（plan）**：访谈信息够用后，先**只输出创作计划**，不是成稿——包含：拟定的核心卖点方向（1-2 个候选）、大纲结构草案（七个大板块各自的要点预告，每块一两句）、关键取舍说明（为什么这么定）。明确标注"这是计划，不是成稿"。
3. **用户确认**：**收到用户明确确认（"可以/就这么定"）后**，才按下述产出流程逐项生成正式内容。用户对计划有修改意见，改完计划再确认一次。

### 必问清单（按优先级）

1. **主题与题材**：想写个什么故事？一句话也行。
2. **男频还是女频**（决定爽点逻辑：男频=升级/征服线为主轴，女频=情感线为主轴）
3. **具体类型**：男频（都市异能/系统流/玄幻修真/历史/科幻/悬疑…）；女频（现言/古言/穿越重生/甜宠/虐恋/修仙/无限流…）
4. **要什么爽点**：见 [references/shuangdian.md](references/shuangdian.md) 的爽点类型库，让用户选或补充
5. **目标平台**（番茄/起点/晋江/七猫…，决定节奏与篇幅预期）与**预计字数**
6. **对标作品**（可选）：有没有想对标的爆款？有则拆其结构做参照
7. **文风 skill**（可选）：是否叠加如 hori-tatsuo-style 等文风约束

## 产出流程（访谈完成后按此顺序逐项产出，每项让用户确认或给默认）

### 1. 核心卖点（一句话）
公式：**【颠覆性身份/处境】+【反常选择/承诺】**。必须是一句能当推荐语的话，先给用户定稿，后面一切从它生长。

### 2. 人物构思
- 主角用**标签法**：贴 5-8 个标签，按重要度排序，牢记第一标签；补齐姓名、外貌、特长、职业、家庭背景、过去创伤/荣耀带来的影响
- **金手指**（男频必备）：规则、代价、成长上限三要素写清
- 人设反差公式：**A 身份 + B 行为/能力，A 与 B 强烈冲突**（保洁阿姨=S 级悬赏犯）
- 配角：女主/男主魅力点、反派动机（反派要有自洽逻辑，不许纸片恶人）、3-5 个功能配角
- 关系方程式：主要角色两两之间的关系模式，一句话一条

### 3. 性格构思
- 性格决定剧情而非相反：写下"主角遇到打脸/背叛/表白/绝境时分别会怎么做"四个反应范式，全书不得违背
- 口癖、小怪癖、底线各一

### 4. 世界观与体系
- 世界观只写**故事运转必需的最小规则**（三根高压线：什么绝对不能发生）
- 男频写力量/等级体系：等级表 + 升级成本 + 战力天花板；女频写情感规则：CP 配置、感情线阶段（相识→拉扯→确认→考验→HE/BE）

### 5. 故事大纲（分级）
- **一级大纲**：全书卷结构，每卷一句话任务 + 卷末大事件
- **二级大纲**：前 3 卷的逐卷详细规划（主线事件序列 + 爽点分布 + 伏笔埋收表）
- **三级大纲**：前 50 章逐章一句话（标出每章爽点与章末钩子）
- 结尾先行：**先预设结局**（男女主归宿、主线谜题答案、最后一幕画面），再倒推关键转折点

### 6. 预设高潮片段
- **黄金三段**（2026 番茄式开头）：第一段冲突前置、第二段人设反差、第三段金句钩子——各写 100-200 字示意
- **3 个大高潮场景**：开局小高潮、全书中间最大爆点、结局高潮，各写一段 200 字左右的"名场面"草稿
- 高潮用**逆推法**：从高潮画面倒推它需要什么铺垫

### 7. 商业包装
书名（3 个候选：一个文艺向、一个直白的番茄风、一个折中）+ 作品简介（300 字内，含钩子）+ 平台标签建议。

## 落盘

全部确认后，在当前工作区建 `<书名>/outline.md`，结构**必须兼容 novel-writing skill 的 outline.md 模板**（立意/人物/结构/分章 beats/意象伏笔清单/写作红线），以便后续直接衔接 novel-writing 的分章流程。访谈记录附在 outline.md 末尾"立项记录"节。

## 禁忌

- 禁止未访谈直接甩一个"看起来很完整"的大纲
- 禁止跳过计划环节：未收到用户对创作计划的明确确认前，禁止生成任何正式大纲内容（哪怕用户只是没回复，也要追问确认，不得默认通过）
- 禁止大纲里只有事件没有人——每个转折点注明"主角此时的心理/性格驱动"
- 禁止爽点均匀分布：爽点要有压抑—爆发循环，标注每处的"压"与"爆"
- 禁止抄袭对标作品的具体情节，只借结构
