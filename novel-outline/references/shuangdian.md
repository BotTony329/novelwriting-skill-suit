# 爽点类型库与男频/女频差异速查

访谈第 4 步（选爽点）和构思时查本表。

## 男频爽点类型（核心驱动：升级与征服）

| 爽点 | 机制 | 经典模板 |
|---|---|---|
| 扮猪吃虎/装逼打脸 | 身份被低估→亮实力→众人震惊 | 退婚流《斗破苍穹》 |
| 重生/穿越先知 | 信息差碾压 | 重生回大学/末世前 |
| 系统流 | 金手指发任务给奖励，升级可视化 | 签到系统、万倍返还 |
| 无敌流 | 开局满级，爽点在他人反应 | 幕后大佬流 |
| 复仇逆袭 | 前期压抑→积蓄→清算 | 赘婿翻身 |
| 收编/势力经营 | 建宗门、收小弟、滚雪球 | 种田流、掌门流 |
| 无限流/智斗 | 规则内破局，逻辑爽 | 《十日终焉》 |

## 女频爽点类型（核心驱动：情感与关系）

| 爽点 | 机制 | 经典模板 |
|---|---|---|
| 甜宠 | 强者独宠我一人 | 霸总/权臣偏爱 |
| 追妻火葬场 | 他辜负→她离开→他疯追 | 虐男向 |
| 重生复仇 | 前世被负→重来一世清算+遇真爱 | 《九重紫》式 |
| 扮猪吃虎（女） | 庶女/病弱实为大佬 | 古言宅斗权谋 |
| 相爱相杀 | 立场对立互相拉扯 | 宿敌CP |
| 双向救赎 | 两个残缺的人互相治愈 | 治愈系现言 |
| 大女主成长 | 情感线+事业线并进 | 女频男频化（《惹金枝》式阳谋权谋） |

## 男频 vs 女频关键差异

| 维度 | 男频 | 女频 |
|---|---|---|
| 主轴 | 升级/事业线，感情为辅 | 情感线为主轴（地位等同男频的升级） |
| 爽点节奏 | 密集，三五章一爆 | 铺垫长，拉扯感优先 |
| 读者诉求 | 建功立业、力量幻想 | 关系中的受惠与被爱、人性温度 |
| 篇幅预期 | 100-300万字+ | 80-150万字 |
| 文笔容忍度 | 较低，剧情为王 | 较高，情感描写要细腻 |

## 开头公式：黄金三段（番茄 2026 流行）

1. **第一段·冲突前置**：砍掉一切背景介绍，第一句就出事。用动作和对话呈现冲突，不写"他很生气"，写"他抓起烟灰缸砸了过去"。500 字内主角必须出场。
2. **第二段·人设反差**：A 身份 + B 行为/能力形成强冲突，第一章就让反差制造第一个爽点。
3. **第三段·金句钩子**：独立成段、能截图传播。类型：反转信息 / 情绪爆发 / 强力承诺 / 揭秘式 / 选择式。

## 新手五大坑（大纲阶段就要规避）

1. 开篇大段铺世界观——世界观藏在剧情里
2. 主角出场太晚——前 500 字必须见到主角
3. 金手指/核心设定拖到第五章才出现
4. 主角太窝囊——可以低谷，但必须有反击苗头
5. 章末没钩子——每章结尾都要给"想看下一章"的理由

## 一致性即爽感

爽感 = 预期的满足 + 意外的惊喜。设定前后矛盾（等级倒退、死人复活、人设崩塌）会直接摧毁爽感——所以大纲阶段必须把等级表、伏笔表、人设反应范式写死，后续衔接 novel-writing skill 的大纲校对流程。
