# 期待感与代入感设计（签约标准层）

## 为什么前六个 skill 还不够

结构工整、逻辑自洽、密度合格的书仍会被拒——编辑看的是**可销售性**：开篇能否瞬间抓住人，大纲能否证明"有料可持续"。本 skill 是签约标准的方法论层，在 novel-outline 立项时和每一章写作时都要执行。

## 一、开篇即时吸引力（黄金 1-3 万字，签约生死线）

三项硬指标，缺一项就改：

1. **主角+核心冲突，3000 字内亮明**：读者要立刻知道"他是谁、他最大的麻烦或渴望是什么"。范式：一句话建立身份与困境（"996猝死的社畜，睁眼成了即将被祭天的奴隶"）。禁止：开篇写景、背景介绍、配角轮番登场。
2. **故事钩子够独特**：金手指/核心梗要么新颖，要么把经典套路做到极致。自检：这个梗一句话说给陌生人听，他会"哦"还是"然后呢？"。
3. **首句即悬念**：第一章第一句最好就是谜面（"不要抬头看月亮"式）。开篇抒情几百字不见事，必死。

## 二、期待感五大发动机（每章至少有一台在转）

1. **目标感**：主角的渴望尽早明牌（报仇/追到她/活下去），大目标管全书，**每 30-50 章必须有一个读者看得见的阶段性目标**——期待来自"我知道他要去哪，我想看他怎么到"。主角随波逐流的章节就是流水账。
2. **信息不对称**：让读者知道主角不知道的事（"反派明天要陷害他，主角还在计划明天"）——产生追更焦虑；或主角知道读者不知道（他的真实计划），产生揭秘期待。
3. **对比法**：过去 vs 现在、主角 vs 他人的落差。羞辱过主角的人，必须安排重逢。
4. **完成欲打断**：奖励即将到手时横生变故，比直接得到更勾人。**章节切分纪律：不要在事件完成处结尾，要在"完成后、变故起"处结尾**——平庸作者写完事，优秀作者挑起事再切。
5. **伏笔即承诺**：每条伏笔都是对读者的欠条，埋的时候就要登记回收节点（衔接 outline 伏笔表）。期待感可以被透支：只埋不收 = 欺骗读者。

## 三、代入感四条纪律

1. **反应正常化**：角色的反应要像正常人——被羞辱会怒、濒死会怕。人物行为一旦违背常识认知，读者立刻出戏（反派降智=代入感崩塌）。
2. **性格留白**：主角性格写到七分，留三分让读者自我投射。性格标签过于具体刁钻，会赶走性格不同的读者。
3. **视角紧贴感知**：读者通过主角的五官进入世界——写他看到的、听到的、皮肤感到的，不写上帝视角的说明书。
4. **利益绑定**：主角的得失必须具体（不只是"很危险"，而是"再输这一场，妹妹的医药费就没了"）。读者代入的不是人设，是**利害关系**。

## 四、情绪三公式（爽感的底层结构）

- **憋屈**（铺垫）：被欺负的场景 + 主角隐忍的反应 + 给读者共情的时间（"等着反击"）
- **爽感**（释放）：憋屈铺垫 + 金手指发力 + 对手/旁观者反应——**爽感的一半在旁观者的震惊里**
- **感动**（粘性）：主角的付出 + 他人的真心反馈

每章自检：本章主情绪是哪个？憋屈之后多少章内必须释放？（压抑超过 5 章不释放，弃书率陡增）

## 执行位置

- **立项时**（配合 novel-outline）：大纲必须标出——终极目标、阶段性目标链（每 30-50 章一个）、每卷的主情绪曲线、核心钩子的一句话测试
- **每章写作时**（配合 novel-writing）：写完自查——本章开了哪台期待感发动机？章末是在"完成处"还是"变故处"切的？代入视角有没有跳出主角感知？
- **审校时**（配合 novel-proofreading）：看客模拟那一遍加问一句——"这一章给了我几个想看下一章的理由？"一个都没有，退回。

## 禁忌

- 禁止把期待感等同于章末"欲知后事如何"——那是形式，发动机才是内容
- 禁止为悬念而悬念：谜面必须有兑现计划，否则是诈骗
- 禁止主角全程被动挨打无目标——代入感的第一死因
